# Gemini CLI Project Rules & Context: Autonomous MT5 Trading Bot

## Project Architecture & Overview
This project is an **Agentic Algorithmic Trading System** integrating Python with MetaTrader 5 (MT5) and the Google Gemini API.

### Core System Blueprint:
1. **Signal EAs (Workers):** Modular Python strategy functions (e.g., RSI Reversion, EMA Crossover) generating trade candidate signals tagged with unique Magic Numbers.
2. **AI Gatekeeper (Manager):** A fast LLM filter (`gemini-2.5-flash`) that evaluates market context (higher timeframe trends, spread, ATR volatility) before approving/vetoing trade signals.
3. **Execution Engine (`tools.py` & `trade.py`):** Connects to MT5, handles order placement, dynamic position sizing, dynamic ATR stop-loss/take-profit, and safety circuit breakers.
4. **Critic Agent (`critic.py`):** An asynchronous weekly review script that analyzes `trade_journal.csv` and recommends rule adjustments for self-improvement.

## 🔒 Mandatory Safety & Risk Invariants (DO NOT BYPASS)

Any code modified or generated by Gemini CLI MUST respect these strict safety rules:

1. **Single-Position Guard (Anti-Machine-Gun):**
   - ALWAYS verify active open positions via `mt5.positions_get(symbol=...)` before scanning for signals or executing trades.
   - NEVER allow duplicate open orders on the same symbol simultaneously.

2. **Dynamic Risk & Position Sizing:**
   - NEVER hardcode fixed lot sizes or point-based stop losses in production execution functions.
   - ALWAYS calculate lot size dynamically using 1% max account equity risk relative to the ATR-based Stop Loss distance.
   - SL must default to **1.5x - 2.0x ATR**, and TP must default to **3.0x - 4.0x ATR** (Minimum 1:2 Risk-to-Reward ratio).

3. **Spread & Liquidity Filter:**
   - ALWAYS check `mt5.symbol_info(symbol).spread` before reviewing signals.
   - If the current spread exceeds the safe threshold (e.g., 500 points for XAUUSD, 2500 points for BTCUSD), IMMEDIATELY skip the cycle.

4. **Hard Circuit Breaker:**
   - Hardcode a daily max drawdown limit (e.g., -$50.00). If total session PnL breaches this limit, forcibly terminate the script and call `mt5.shutdown()`. Do not rely solely on the LLM to halt trading.

5. **Mandatory Startup Diagnostic:**
   - Every execution run MUST execute `run_startup_test()` (a 0.01 micro-trade BUY followed by an immediate CLOSE) before entering the infinite trading loop.
